# 👑 منصة وتطبيق كايدو فولو | Kaido Follow (Full Platform + Auto APK)

هذا المجلد يحتوي على المنصة الكاملة (تطبيق المستخدم + لوحة الإدارة الشاملة + محرك التحويل التلقائي إلى تطبيق أندرويد `.apk` عبر GitHub Actions).

## 📁 محتويات الحزمة:
1. `index.html` و `www/index.html`: **تطبيق المستخدم الكامل** (شاشة بداية مستقرة، شريط إعلانات بشعار التطبيق الفاصل، أقسام بصور مضبوطة 55px، إشعارات فورية، سجل مالي بالتاريخ والوقت، كود دعوة وأرباح، ودعم فني مباشر).
2. `admin.html` و `www/admin.html`: **لوحة الإدارة الشاملة** مربوطة بـ Firebase بالكامل (إحصائيات، شحن/خصم رصيد، أقسام، خدمات، مزودين API، كوبونات، تذاكر دعم، إشعارات، وأداة بناء APK).
3. `.github/workflows/build-apk.yml`: **محرك البناء التلقائي** الذي يحول المشروع إلى ملف `Kaido-Follow.apk` فور رفعه على GitHub.
4. `package.json` و `capacitor.config.json`: ملفات تعريف تطبيق الأندرويد.

---

## 🚀 خطوات التحويل إلى APK عبر GitHub من هاتفك:
1. فك الضغط عن هذا الملف `Kaido-Follow-Full-Project.zip`.
2. أنشئ مستودعاً جديداً (Repository) في حسابك على **GitHub**.
3. ارفع جميع الملفات والمجلدات الموجودة داخل الحزمة إلى المستودع (تأكد من وجود ملف `.github/workflows/build-apk.yml`).
4. بمجرد حفظ الملفات، سيبدأ GitHub تلقائياً ببناء التطبيق في قسم **Actions** (يستغرق دقيقتين فقط).
5. بعد انتهاء البناء، ادخل إلى قسم **Releases** في مستودعك، وستجد ملف **`Kaido-Follow.apk`** جاهزاً للتحميل والتثبيت بضغطة زر واحدة على هاتفك!
